# Flamengo - História e Cultura

prova de desenvolvimento de front end para web usando apensas html

## Objetivo

contar a historia do meu time

## Páginas

- index.html - Página inicial
- historia.html - História e informações
- contato.html - Formulário

## Recursos HTML utilizados

- HTML semântico
- Links de navegação
- Tabela
- Formulário
- Figure e figcaption
- Details e summary
- Blockquote
- Mark
- Abbr
- Bdi
- Progress
- Meter
- Áudio
- Vídeo
- Time
- Comentários HTML

## Tecnologias

somente HTML5.
